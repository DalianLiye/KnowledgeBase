# 应用性能监控
英文:Application Performance Monitoring, APM\
专门监测应用程序运行状态，定位卡顿、报错、响应慢等问题的技术体系

**核心监控维度**
- 性能指标：接口耗时、吞吐量、错误率、资源占用
- 链路追踪：请求从入口到各服务、数据库的完整调用流程
- 故障诊断：自动分析异常根因，给出优化建议

# 负载均衡
英文:Server Load Balancer,SLB
SLB包括以下：
- **网络型负载均衡**\
  Network Load Balancer, NLB\
  四层 TCP/UDP，高并发、低时延业务

- **应用型负载均衡**\
  Application Load Balancer,ALB\
  七层 HTTP/HTTPS，面向网页、微服务

- **传统负载均衡**\
  Classic Load Balancer，CLB
  四层 + 七层通用，老旧业务适配


# Web应用与API防护
英文：Web Application and API Protection，WAAP
保护网站、H5、APP 后端、各种 API 的综合安全产品
不仅做WAF（防 SQL 注入、XSS 等 Web 攻击），还多了：
- API安全：发现接口、防越权、防刷接口
- Bot/爬虫管理：识别恶意爬虫、刷票、薅羊毛
- DDoS防护：抗大流量攻击
