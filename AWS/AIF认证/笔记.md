# SageMaker
- SageMaker Data Wrangler
只负责数据准备清洗，不能训练ML模型
- SageMaker Canvas
  无代码，一站式：导入数据 → 构建模型 → 生成预测，面向不懂代码的业务人员

# Amazon Bedrock
AWS完全托管、无服务器的生成式AI平台
不用自己搭建、运行大模型硬件，通过API调用各家现成基础模型 (FM)，用来开发生成式AI应用

## Bedrock微调模型
- 在Bedrock内部使用微调后的自定义模型，必须购买Provisioned Throughput（预调配吞吐量）
- 如果导出模型部署到SageMaker endpoint，就不再通过Bedrock使用模型
- Bedrock自动模型评估：用来测试模型质量，不属于安全访问控制
- PartyRock：Bedrock网页游乐场原型工具，不能部署到VPC

## Prompt工程
- Few‑shot少样本提示：给若干输入输出示例，适合分类任务（情感正负分类）
- 想要控制输出语气、品牌口吻：优化/迭代提示词；调高temperature会让输出更随机发散
- token limit：只控制输出长度，不控制风格

## Bedrock 安全
IAM 最小权限原则是核心安全手段


# 各类模型概念

## 模型架构
- **BERT**：双向编码器，擅长理解、分类；不擅长生成。
- **GPT**：自回归解码器，擅长文本生成。
- **Multi‑modal embedding 多模态嵌入模型**：文本 + 图像转向量，用于图文搜索。
- Multimodal generation：多模态生成，不是检索搜索

## 机器学习类型
1. **Supervised 监督学习**：带标注数据集训练。
2. **Unsupervised 无监督**：聚类，找相似样本分组。
3. **Reinforcement Learning 强化学习**：依靠用户反馈作为奖励信号，模型**自我迭代改进**（客服机器人从交互中优化回答）。
4. Prescriptive ML 指令型模型：给出建议动作；Predictive 预测型：预测未来结果；Descriptive 描述型：描述已经发生的事实

## 评估指标
- **BLEU**：机器翻译任务指标
- **ROUGE**：文本摘要任务指标
- **RMSE**：回归问题
- **F1‑score**：分类任务
- Inference responses：模型推理输出结果

## 模型偏见 Bias（负责任 AI 考点）
- **Sampling bias 采样偏差**：训练数据集样本不均衡，导致对特定群体误判（监控摄像头过度标记某一族裔）。
- Measurement bias 测量偏差：度量指标设计缺陷。
- Observer bias 观察者偏差：标注人员主观带入偏见。
- Confirmation bias 确认偏差：只采信符合自己观点的证据

## 负责任生成式 AI 风险
- Plagiarism：抄袭，直接复制 AI 输出当做自己内容。
- Hallucinations：幻觉，模型编造虚假事实。
- Toxicity：输出歧视、有害内容。
- Privacy：隐私泄露风险

# AWS 服务速记
1. **Amazon Comprehend**：NLP 文本分析，情感分析、主题挖掘、提取高频问题、业务洞察。
2. **Amazon Lex**：搭建聊天机器人对话交互。
3. **Amazon Transcribe**：语音转文本；**只转文字，不做内容分析**。
4. **Amazon Translate**：文本翻译。
5. **Amazon Rekognition**：图像、视频识别。
6. **Amazon Personalize**：业务个性化推荐。
7. **AWS Glue**：ETL，非结构化数据 → 转换为结构化数据。
8. **Kinesis Data Streams**：接收处理实时流数据。
9. **SageMaker JumpStart**：一键部署现成基础模型，可部署到**自己 VPC 内**；快速获得 FM 端点。
   - SageMaker Endpoints：是部署产物，不是快速部署工具。
10. **SageMaker Model Registry**：模型版本管理，和 Bedrock 微调模型无关

# 推理、性能、运维考点
1. **Provisioned Throughput**：Bedrock 预留吞吐量，微调模型调用必须购买。
2. Inference：推理，模型运行得到输出。
3. Ongoing pre‑training 持续预训练：使用新数据继续预训练，**随时间提升模型性能**；不会降低复杂度、不会加快推理、不会减少训练耗时。
4. Batch inferencing 批量推理：批量处理多条请求，和控制输出语气无关。
5. CloudWatch Logs：可以日志记录；**不能直接实现模型可解释性，不能直接监控偏见**。
6. Audit Manager：用于合规审计，不是模型自动评估
