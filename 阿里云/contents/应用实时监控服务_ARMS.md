# 关于应用实时监控服务
英文:Application Real-Time Monitoring Service, ARMS
阿里云统一的全栈可观测平台，实现端到端全链路追踪 + 应用性能监控 + 日志/指标/链路统一分析 + 智能告警诊断

监控覆盖体系：
- 前端：网页（Web/H5）、小程序、App（iOS/Android）
- 后端：Java、PHP、Go、Python 等服务、微服务、容器、ECS
- 中间件 / 数据库：MySQL、Redis、MQ、Nginx 等
- 基础设施：主机、网络、K8s 集群
- 大模型应用：通义千问、LangChain 等链路与性能

有了ARMS就无需为各体系单独配置监控
