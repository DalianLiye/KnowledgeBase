# 关于选择器
选择器(Selector)就是根据标签筛选资源的工具\
用于匹配带有指定标签的资源, 是K8s实现关联、调度、管理的核心机制

# 选择器配置
选择器的配置方式有以下几种:

- **定义配置文件**\
  在各对象的配置spec.selector或其他可以写selector的属性中编写

- **kubectl命令**\
  示例1: 匹配单个值，查找app=hello的pod
  ```shell
  kubectl get po -A -l app=hello
  ```
  
  示例2:匹配多个值
  ```shell
  kubectl get po -A -l 'k8s-app in (metrics-server,kubernetes-dashboard)'
  ```

  示例3:查找version!=1 and app=nginx的pod信息
  ```shell
  kubectl get po -l version!=1,app=nginx
  ```

  示例4:不等值+语句
  ```shell
  kubectl get po -l 'version!=1,app=nginx,test in (xxx,xxx,xxx)
  ```
