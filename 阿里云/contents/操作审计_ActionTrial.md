# 关于操作审计
英文：Action Trail
阿里云账号全行为日志记录服务，相当于云上操作黑匣子，追溯所有管控类操作，专门用来记录阿里云上各种操作的
对标：AWS Cloudtrial


# 记录范围
记录范围包括以下：
- 控制台手动点击操作
- API、SDK、CLI、AK 密钥调用请求
- 云服务间角色授权交互操作


# 核心特性
默认自动开启，免费日志留存90天
支持自定义跟踪，长期归档至OSS、SLS、MaxCompute
区分管理事件、数据事件，对象级访问可按需开启采集
支持异常操作识别，风险行为可告警


# 核心用途
故障追溯：定位配置变更、资源删除等问题根源
安全排查：核查密钥滥用、陌生IP违规操作
合规审计：满足等保要求，留存操作凭证
权限核查：梳理账号操作行为，优化权限体系


# 运维日常工作
定期查看操作日志，巡检高危操作记录
配置日志持久化归档，保障数据长期可查
故障时检索日志，定位操作诱因
配合RAM权限体系，管控账号操作风险


# 关联服务
RAM权限管理、云安全中心、SLS日志服务
