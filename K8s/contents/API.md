# 关于API
**API版本说明**\
- **Alpha**\
  尝鲜版本，内置最新功能，但稳定性差、可能存在缺陷，仅适用于短期测试与功能验证
- **Beta**\
  已完成充分测试，整体可用，但部分细节、接口仍可能调整变更
- **Stable**\
  正式稳定版本，可直接应用于生产环境


**废弃api说明**\
K8s官方废弃API规则及迁移指南：\
https://kubernetes.io/zh-cn/docs/reference/using-api/deprecation-guide/


**K8s API管理资源范围**\
K8s API可对以下资源进行交互管理：
- 运行中的Pod
- 集群节点与整个集群
