# 关于资源
K8s理念：一切皆资源，万物皆对象\
如果将K8s资源比作Java类，K8s对象是基于资源定义创建的实例

K8s中的所有内容都被抽象为"资源"\
资源类别包括：Pod，Service，Node等\
K8s对象就是资源的实例，是持久化的实体，例如：某个具体的pod或Node\

K8s通过这些实体描绘出整个集群的状态\
集群里每一个真实组件，都会对应一个K8s对象实例，比如哪些个节点，Pod，Service对象\
K8s通过这些实例来记录、管控集群当下真实情况

对象的创建，删除，修改都是通过"kubernetes API"，也就是kube-apiserver组件提供的API接口实现的\
命令行工具kubectl实际上也是调用kubernetes API

可以通过"kubectl命令 + 配置文件"来创建这些对象\
配置文件就是声明式定义对象期望状态的文件\
配置文件格式可以是json或yaml，生产环境常用yaml
