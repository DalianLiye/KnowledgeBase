# 关于工具

Agent不仅可以绑定模型，通过工具可以让Agent有了采取行动的能力，包括：
- 串行或并行的调用Tool
- 根据结果动态选择执行Tool
- retry和error处理
- 跨工具调用的状态持久化

工具支持普通Python函数与协程（coroutines）

# 工具调用流程
1) 用户提问 
2) Agent把问题 + 工具描述传给模型
3) 模型判断需要调用工具，生成调用请求
4) Agent接收请求，查找并运行对应工具
5) 工具执行完毕返回数据 
6) 将返回数据再交由模型整合输出最终回答

**注：**\
模型负责决策要不要调、调哪个工具\
Agent负责实际执行工具

具体分工：
- **模型的工作**\
  接收用户问题 + 工具信息，判断业务逻辑，输出工具调用指令，只做决策，不跑代码
- **Agent的工作**\
  解析模型下发的调用指令，匹配对应工具函数，真正执行代码逻辑，拿到结果再回传给模型
